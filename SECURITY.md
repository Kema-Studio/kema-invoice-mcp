# Security

The Kema Invoice MCP server handles invoicing data. If you find a vulnerability in the connector, the OAuth flow or this repository, please report it privately to **hello@kema-studio.com** (subject: Security) with steps to reproduce. We acknowledge reports within 3 working days and keep you informed until the fix is deployed. Please do not open a public issue for security matters.

Scope: `mcp.kema-studio.com`, `auth.kema-studio.com`, `invoice.kema-studio.com` and the scripts in this repository. Out of scope: denial of service, social engineering, third-party services we integrate with.
